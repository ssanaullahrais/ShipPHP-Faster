Initialize New Project

Set up ShipPHP to deploy your local files to a remote server.

Setup Instructions:

  1. Generate shipphp-server.php using CLI: shipphp server generate
  2. Upload the generated file to your web server
  3. Copy the server URL and authentication token from the file
  4. Enter the details below to complete setup

Or click Generate to create a new token (remember to update your server file)
